# Лабораторная №7 — Активное обучение

Система поддержки экспериментов активного обучения нейросетей. Самостоятельный учебный прототип по мотивам лабораторной №6.

## Запуск
1. Установить Docker Desktop.
2. `docker compose up --build` из папки проекта.
3. Открыть http://localhost:8501 (Streamlit) и http://localhost:8000/docs (FastAPI).
4. Логины: admin/admin123, engineer/engineer123, student/student123 (только демонстрация).
5. При необходимости `cp .env.example .env`, настроить LLM и перезапустить. Без ключа используется шаблон.

## Проверка без Docker
`pip install -r requirements.txt` и `python run_checks.py`.

## Ограничения
- Для локального обучения: авторизация защищает интерфейс, но не API; API привязан к 127.0.0.1.
- Заявки хранятся в памяти, перезапуск сбрасывает добавленные заявки.
- При отсутствии LLM_API_KEY реальная модель не вызывается.
- TF-IDF используется вместо тяжёлого эмбеддинг-индекса, чтобы снизить требования к памяти.
